\# Customer Shopping Behavior Analysis



\## Overview



This project analyzes customer shopping behavior using transactional data to identify patterns in spending, customer segments, product preferences, discounts, shipping, and subscription behavior.



The project demonstrates an end-to-end data analytics workflow using Python, SQL, Excel, and Power BI.



\## Business Problem



The goal is to understand customer shopping behavior and identify insights that can support sales, customer engagement, loyalty, marketing, and product strategies.



\## Tools



\- Python

\- Pandas

\- PostgreSQL

\- SQL

\- Excel

\- Power BI

\- Git / GitHub



\## Project Workflow



Raw Data

→ Python Data Preparation

→ PostgreSQL / SQL Analysis

→ Excel Ad-hoc Analysis

→ Power BI Dashboard

→ Business Recommendations



\## Dataset



The dataset contains 3,900 purchase records and 18 columns covering customer demographics, purchase details, and shopping behavior.
